    **`GraphIsland` interface:**
    ```typescript
    export interface GraphIsland {
      nodeIds: Set<string>
      edges: SymbolEdge[]
    }
    ```

    **`findIslands(nodeIds: string[], edges: SymbolEdge[]): GraphIsland[]`**
    - Build undirected adjacency list from edges (both source→target and target→source)
    - BFS from each unvisited node to find connected components
    - Return array of GraphIsland with nodeIds Set and filtered edges

    **`estimateNodeDimensions(isExpanded: boolean, memberCount: number, sectionCount: number): { width: number; height: number }`**
    - Compact: `{ width: 200, height: 60 }`
    - Expanded: `{ width: 280, height: Math.max(80, 44 + sectionCount * 28 + memberCount * 24 + 20) }`

    **`NodeInfo` interface for layout input:**
    ```typescript
    export interface NodeInfo {
      width: number
      height: number
      data: Record<string, unknown>
    }
    ```

    **`LayoutResult` interface:**
    ```typescript
    export interface LayoutResult {
      positions: Map<string, { x: number; y: number }>
    }
    ```

    **`layoutIslands(islands: GraphIsland[], nodeMap: Map<string, NodeInfo>, focusedClassId: string | null): LayoutResult`**
    - Sort islands: island containing focusedClassId first, then by size descending
    - For each island, create a fresh dagre `graphlib.Graph`, set `{ rankdir: 'TB', nodesep: 60, ranksep: 120, marginx: 20, marginy: 20 }`
    - Add nodes with width/height from nodeMap
    - Add edges — **CRITICAL**: for `EdgeKind.Inherits` edges, REVERSE direction: `g.setEdge(edge.target, edge.source)` so base classes rank above derived. For all other edges, use `g.setEdge(edge.source, edge.target)`.
    - Run `dagre.layout(g)`
    - Convert dagre center-anchor positions to top-left: `x = dagreNode.x - width/2`, `y = dagreNode.y - height/2`
    - Track island bounding box, apply xOffset between islands with `ISLAND_GAP = 200`
    - Return Map of nodeId → {x, y} positions

    **`mergeGraphs(existing: CodeGraph | null, incoming: CodeGraph): CodeGraph`**
    - Deduplicate nodes by id (Map<string, CodeSymbol>)
    - Deduplicate edges by id (Map<string, SymbolEdge>)
    - Return merged CodeGraph

    **`removeClassFromGraph(graph: CodeGraph, classId: string): CodeGraph`**
    - Remove nodes where id === classId
    - Remove edges where source === classId or target === classId
    - Return filtered CodeGraph

    3. Create `src/utils/__tests__/graphLayout.test.ts` with tests for all behaviors listed above.

    ```typescript
    pinClass: async (classId: string) => {
      const state = get()
      if (state.pinnedClassIds.has(classId)) return // already pinned

      set({ isLoadingPin: true })
      try {
        const [detail, hierarchy] = await Promise.all([
          api.getClassDetail(classId),
          api.getClassHierarchy(classId),
        ])
        if (!detail) { set({ isLoadingPin: false }); return }

        set(s => {
          const newPinnedIds = new Set(s.pinnedClassIds)
          newPinnedIds.add(classId)
          const newPinnedClasses = new Map(s.pinnedClasses)
          newPinnedClasses.set(classId, detail)
          const newMultiGraph = mergeGraphs(s.multiGraph, hierarchy)

          return {
            pinnedClassIds: newPinnedIds,
            pinnedClasses: newPinnedClasses,
            multiGraph: newMultiGraph,
            focusedClassId: classId,
            isLoadingPin: false,
          }
        })

        // Load source for the newly focused class
        if (detail.location) {
          await get().loadSource(detail.location.file, detail.location.line)
        }
      } catch (err) {
        console.error('Failed to pin class:', err)
        set({ isLoadingPin: false })
      }
    },
    ```

    **5. Implement `unpinClass` action:**
    ```typescript
    unpinClass: (classId: string) => {
      set(s => {
        const newPinnedIds = new Set(s.pinnedClassIds)
        newPinnedIds.delete(classId)
        const newPinnedClasses = new Map(s.pinnedClasses)
        newPinnedClasses.delete(classId)

        // Rebuild multiGraph from remaining pinned classes
        // (simplest approach: we need to re-merge, but we don't cache individual hierarchies)
        // For now, remove this class's nodes/edges from the graph
        const newMultiGraph = removeClassFromGraph(s.multiGraph, classId)

        // If the unpinned class was focused, focus the first remaining pin
        let newFocusedId = s.focusedClassId
        if (newFocusedId === classId) {
          newFocusedId = newPinnedIds.size > 0 ? [...newPinnedIds][0] : null
        }

        return {
          pinnedClassIds: newPinnedIds,
          pinnedClasses: newPinnedClasses,
          multiGraph: newPinnedIds.size === 0 ? null : newMultiGraph,
          focusedClassId: newFocusedId,
        }
      })
    },
    ```
