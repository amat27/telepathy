<objective>
Make the SymbolTree filter input responsive by adding debounce and stale-result cancellation.

Purpose: Currently `setClassFilter` fires an IPC+SQL query on every keystroke, causing UI freezes and race conditions where stale results overwrite newer ones. This plan adds (1) a 200ms debounce in the component, (2) a request-ID guard in the store to discard stale responses, and (3) a loading indicator.

Output: Modified `appStore.ts`, `SymbolTree.tsx`, and `SymbolTree.css` — filter typing is instant, IPC calls are debounced, stale results are discarded.
</objective>
